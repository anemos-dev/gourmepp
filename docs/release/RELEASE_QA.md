# ごはん日和 初版リリースQA

初版の提出候補ビルドをTestFlightへ配布したあと、iPhone実機で以下を確認します。各項目は、許可済みの端末だけでなく、アプリを削除して権限が未決定の状態でも実施します。

## 基本導線

- [ ] 初回起動でオンボーディングが最後まで表示される
- [ ] 店舗を手入力して「行った」「行きたい」の記録を保存できる
- [ ] 店舗検索が成功し、オフライン時には操作可能なエラー表示になる
- [ ] 記録の編集、ゴミ箱への移動、復元、完全削除ができる
- [ ] 電話、Webサイト、Apple Maps、共有シートが正しい内容で開く

## 権限と写真

- [ ] 「記録する」を開いただけでは位置情報ダイアログが表示されない
- [ ] 「現在地を使う」を押したときだけ位置情報ダイアログが表示される
- [ ] 位置情報を拒否しても、店舗検索と手入力を続けられる
- [ ] 写真を「許可」「選択した写真のみ」「拒否」の各状態で追加できる、または適切な案内が出る
- [ ] カメラを許可・拒否した場合の両方で画面が操作不能にならない
- [ ] 複数写真の追加、並べ替え、削除後に再起動しても内容が維持される

## データ保全

- [ ] 写真を含むバックアップを書き出し、別の初期状態端末へ復元できる
- [ ] CSVとEPUBを書き出せる
- [ ] EPUBを取り込み、重複が二重登録されない
- [ ] 空き容量が少ない状態で写真保存に失敗しても、既存記録が消えない
- [ ] アプリ更新後も既存の記録、写真、タグ、まとめを開ける

## ごはん日和 Pro / TestFlight

- [ ] Sandboxテスターで非消費型商品 `com.anemos.gohanbiyori.pro.lifetime` の価格が表示される
- [ ] 購入成功後、年間レポートなどのPro機能が即時解放される
- [ ] 購入画面のキャンセル後も通常機能を利用できる
- [ ] Ask to Buyなどの承認待ちでは「承認待ち」と表示される
- [ ] アプリ再インストール後に「購入を復元」でProが戻る
- [ ] 返金・失効した取引では次回の権利更新後にProがロックされる
- [ ] オフライン時の商品取得・購入・復元エラーが日本語で表示される

## 提出候補

- [ ] iPhoneの小さい画面と大きい画面で文字切れがない
- [ ] ライト／ダーク表示で読めない文字やアイコンがない
- [ ] VoiceOverで主要ボタンと店舗カードを識別できる
- [ ] Release構成でArchiveし、App Store Connectへのアップロード検証が成功する
- [ ] App Store Connectのプライバシー回答、スクリーンショット、審査メモがビルド内容と一致する
