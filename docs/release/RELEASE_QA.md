# グルメップ 初版リリースQA

初版の提出候補ビルドをTestFlightへ配布したあと、iPhone実機で以下を確認します。各項目は、許可済みの端末だけでなく、アプリを削除して権限が未決定の状態でも実施します。

## 基本導線

- [ ] 初回起動でオンボーディングが最後まで表示される
- [ ] 店舗を手入力して「行った」「行きたい」の記録を保存できる
- [ ] 店舗検索が成功し、オフライン時には操作可能なエラー表示になる
- [ ] 記録の編集、ゴミ箱への移動、復元、完全削除ができる
- [ ] 電話、Webサイト、Apple Maps、共有シートが正しい内容で開く

## 権限と写真

- [ ] 「記録する」を開いただけでは位置情報ダイアログが表示されない
- [ ] 「現在地を使う」を押したときだけ位置情報ダイアログが表示される
- [ ] 位置情報を拒否しても、店舗検索と手入力を続けられる
- [ ] 写真を「許可」「選択した写真のみ」「拒否」の各状態で追加できる、または適切な案内が出る
- [ ] カメラを許可・拒否した場合の両方で画面が操作不能にならない
- [ ] 複数写真の追加、並べ替え、削除後に再起動しても内容が維持される

## データ保全

- [ ] 写真を含むバックアップを書き出し、別の初期状態端末へ復元できる
- [ ] CSVとEPUBを書き出せる
- [ ] EPUBを取り込み、重複が二重登録されない
- [ ] 空き容量が少ない状態で写真保存に失敗しても、既存記録が消えない
- [ ] アプリ更新後も既存の記録、写真、タグ、まとめを開ける

## グルメップ Pro / TestFlight

- [ ] Sandboxテスターで非消費型商品 `com.anemos.gourmepp.pro.lifetime` の価格が表示される
- [ ] 購入成功後、年間レポートなどのPro機能が即時解放される
- [ ] 購入画面のキャンセル後も通常機能を利用できる
- [ ] Ask to Buyなどの承認待ちでは「承認待ち」と表示される
- [ ] アプリ再インストール後に「購入を復元」でProが戻る
- [ ] 返金・失効した取引では次回の権利更新後にProがロックされる
- [ ] オフライン時の商品取得・購入・復元エラーが日本語で表示される

## 提出候補

- [ ] iPhoneの小さい画面と大きい画面で文字切れがない
- [ ] ライト／ダーク表示で読めない文字やアイコンがない
- [ ] VoiceOverで主要ボタンと店舗カードを識別できる
- [ ] Release構成でArchiveし、App Store Connectへのアップロード検証が成功する
- [ ] App Store Connectのプライバシー回答、スクリーンショット、審査メモがビルド内容と一致する

## 記録体験の改善（feature/record-experience-improvements）

以下は今回追加した機能の実機確認項目です。未チェックは未検証です。

- [ ] 「行きたい」の詳細から「行ったにする」を開き、訪問日・評価・写真を入力して保存できる。キャンセルすると状態・日付・写真が変わらない。
- [ ] 新規記録・編集で写真を選ぶと撮影日の候補が表示され、選択した場合だけ訪問日に反映される。撮影日なし・複数日・選択変更・読み込み失敗でも手入力を続けられる。
- [ ] 無料でも「次に食べたい · Pro」が表示され、購入画面へ進める。Proでは店舗別に保存でき、同じ店舗の次回記録へ引き継がれる。無料へ戻っても既存メモは消えず、編集はできない。
- [ ] 「また行きたい」が評価・お気に入りと独立して保存され、一覧のマークと絞り込みに反映される。
- [ ] 店舗詳細からまとめを作成すると、その記録が同時に追加される。空白だけの名前では作成できない。
- [ ] ホームの表示メニューから一括整理を開き、選択した記録だけにタグ・まとめ追加・ゴミ箱移動が反映される。再追加してもタグ・まとめ所属は重複しない。ゴミ箱移動は確認・キャンセル・復元できる。
- [ ] 「Ｃａｆｅ／cafe」「ｶﾞｰﾃﾞﾝ／がーでん」「プリン／ぷりん」で同じ記録が検索される。濁点の有無やタグ条件は区別される。
- [ ] 設定の月間レポートで年・月を切り替え、訪問数・店舗数・新規開拓・平均評価を確認する。月末・年跨ぎ・未評価・日付なし・ゴミ箱・未訪問の扱いを確認する。利用条件は年間レポートと同じPro。
- [ ] バックアップ書き出し成功後に作成履歴が更新され、キャンセル・失敗時は更新されない。記録・店舗メモ・写真・メニュー・タグ・まとめを変更すると未バックアップ表示になる。
- [ ] 新形式バックアップから「次に食べたい」「また行きたい」を復元できる。旧形式は空欄／オフで復元される。復元・全削除時は端末のバックアップ作成履歴がリセットされる。
- [ ] 旧バージョンの端末内ストアから更新し、既存の記録・写真を維持して新項目を保存できる。

自動検証用に `RecordExperienceTests.swift` を追加。Simulator生成を避けるため、今回のロジック検証と旧モデルからのストア移行確認はmacOS上で行い、iOSテストはコンパイルのみ実施済み。実機の購入・写真ライブラリ・ファイル書き出し操作は別途確認する。
